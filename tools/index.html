🛠 Free Tools

Fourteen free tools that run entirely in your browser. No sign-up, no data sent to any server, no cost — made by AYAN XD.

🔐

Password Generator

Generate a strong random password in your browser. Uses your device's cryptographic random generator — the password never leaves this page.

🔥

Password Strength Checker

Check how strong your password is. The check runs entirely in your browser — your password is never sent anywhere.

🔐

Hash Generator

Compute MD5, SHA-1, SHA-256 and SHA-512 hashes for any text, side by side. Useful to verify file or text integrity.

🔗

Base64 Encoder / Decoder

Encode text to Base64 or decode Base64 back to text. Unicode-safe, with an optional URL-safe variant.

🔗

URL Encoder / Decoder

Percent-encode text for safe use in URLs, or decode a percent-encoded URL back to readable text.

</>

HTML Entity Encoder / Decoder

Encode special characters as HTML entities (& < > etc.) or decode entities back to normal text.

🔐

JWT Decoder

Decode a JSON Web Token to see its header and payload claims. Decoding is NOT verification — the signature is not checked here.

🎲

UUID Generator

Generate cryptographically random version 4 UUIDs, one at a time or in bulk.

🔢

Binary / Decimal / Hex Converter

Convert numbers between binary, decimal and hexadecimal. Works with very large numbers too.

🔐

TOTP Generator

Generate the current 6-digit authenticator code from your Base32 secret — like Google Authenticator, but right here in the browser. Your secret never leaves this page.

🔔

Morse Code Encoder / Decoder

Turn text into Morse code (dots and dashes) or decode Morse code back into text.

🔐

Caesar Cipher

Shift every letter by a chosen amount — the classic Caesar cipher. Includes a ROT13 preset.

🖼

QR Code Generator

Turn any text or link into a scannable QR code. The QR is generated in your browser — scan it with any phone camera.

🎲

Fake Data Generator

Generate fictional test data — a fake name, email, Pakistani-format mobile, address and username. TEST DATA ONLY: none of it is real.
Use them fairly. These tools are for your own systems, your own accounts, or systems you have permission to test. Do not use them to access, copy or expose anyone else's private data.
